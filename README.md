# Nakama CMS Universal

Nakama CMS is a reusable website generator for Nakama Digital.

## Architecture

```text
CMS React/Vite (GitHub Pages)
          |
          v
Google Apps Script Web App
          |
          +---- Google Sheets (customers + websites)
          |
          +---- GitHub REST API
                    |
                    +---- customer repository
                    |
                    +---- GitHub Pages website
```

## Included

- Premium theme library: 12 themes
- Customer management
- Website management
- Apps Script API connector
- Google Sheets database
- Automatic GitHub repository generation
- Theme file copying from this repository
- Automatic GitHub Pages configuration
- GitHub Actions deployment for the CMS itself
- Responsive dashboard

## Important

The GitHub token belongs in Apps Script Script Properties only. Never put the token in `public/config.json`, frontend TypeScript, or GitHub Actions source files.

## Backend setup

See `apps-script/README.md` and copy `apps-script/Code.gs` into a Google Apps Script project.

## GitHub Pages

GitHub Pages is used for static websites. The included workflow builds this Vite project and publishes `dist/` to GitHub Pages. Customer websites generated by Apps Script are also static GitHub Pages sites.
